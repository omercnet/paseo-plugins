Context Mode connects Paseo agents to [Context Mode](https://github.com/mksglu/context-mode), a separate tool that runs as an MCP server and gives agents tools for indexing and searching project knowledge. The plugin bundles Context Mode 1.0.169 and adds a screen with health, savings, and a knowledge search and indexing panel. It supports the Claude, Codex, Copilot, Cursor, OpenCode, Pi, and OMP providers and leaves others unchanged. It needs Paseo 0.9 to 0.11 and Node.js 24 or later on the daemon host.

By default, creating a supported agent adds a Context Mode MCP server to it. Existing agents do not get the server, and opening or resuming a session only sets two environment variables that name the provider and its data folder, with a separate folder per provider. Turning off automatic activation stops the plugin adding these from then on, and it does not remove them from agents that already have them. A server you configured yourself is kept. By default the plugin also reads each provider's config files and skips its own addition when Context Mode is already registered there.

The plugin starts the Context Mode process on the daemon host. It reads Context Mode's local databases read-only to build the savings dashboard. Indexing a path reads files under it on the host into Context Mode's knowledge store, and indexing a URL makes Context Mode download that page from the host. The install and upgrade actions on the Setup tab only display a command, and the plugin never runs it. What the agents' Context Mode tools do is up to Context Mode.
